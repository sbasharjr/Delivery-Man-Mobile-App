================================================================================
API ENDPOINTS
================================================================================

The app expects these endpoints at https://mygetwell.app/api:

POST   /delivery/login              # Authenticate
POST   /delivery/register           # Register new user
GET    /delivery/orders             # Fetch orders
GET    /delivery/orders/:id         # Fetch order details
PUT    /delivery/orders/:id/status  # Update order status
PUT    /delivery/profile            # Update profile
