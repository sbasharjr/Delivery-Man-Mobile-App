# Changelog

All notable changes to the MyGetWell Vendor Mobile App will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-01

### Added
- Initial release of MyGetWell Vendor Mobile App
- Complete Flutter project structure
- Authentication system with login screen
- Dashboard with business statistics
- Orders management screen
- Products inventory screen
- Vendor profile screen
- Splash screen with branding
- Bottom navigation
- State management with Provider
- Mock authentication service
- Data models for Vendor, Product, and Order
- Form validation
- Session management with SharedPreferences
- Android platform configuration
- iOS platform configuration
- Unit tests for data models
- Comprehensive documentation
- README with setup instructions
- Quick start guide
- Project summary

### Features
- Login with email and password
- View dashboard statistics (Orders, Revenue, Products)
- Browse orders with status indicators
- View products in grid layout
- Manage vendor profile
- Logout functionality
- Session persistence
- Responsive UI design
- Material Design 3 theme

### Technical
- Flutter SDK 3.0+ support
- Dart 3.0+ support
- Provider for state management
- HTTP client ready for API integration
- SharedPreferences for local storage
- Internationalization support (Intl package)
- Clean architecture
- Separation of concerns
- Type-safe code
- Linting configured

### Platforms
- Android (minimum SDK 21)
- iOS (minimum version as per Flutter)

### Dependencies
- flutter: SDK
- provider: ^6.0.5
- http: ^1.1.0
- shared_preferences: ^2.2.2
- intl: ^0.18.1
- cupertino_icons: ^1.0.2
- flutter_lints: ^2.0.0
